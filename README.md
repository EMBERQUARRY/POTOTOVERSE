# Pototoverse

A minimal Fabric mod skeleton for Pototoverse.

This repository is intentionally set up as a small, buildable starting point before adding the full potato content.

## Target stack
- Minecraft: 1.20.1
- Fabric Loader: 0.15.11
- Fabric API: 0.92.2+1.20.1
- Java: 17

## Run locally
1. Install JDK 17.
2. Run: `./gradlew build`
3. The built jar will be placed under `build/libs/`.

## Notes
This is Stage 1 only: a minimal mod entry point and project scaffolding.
